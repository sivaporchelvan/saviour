# Project Brief

## Product concept
SIVA is a personal, contemplative, interactive 3D experience devoted to Lord Siva. It is designed as a quiet digital shrine and exploratory environment: a browser-based scene where a visitor can orbit around sacred forms, select symbols, and read short English/Tamil explanations without becoming a heavy information dashboard.

## Audience
- Devotees seeking a sensory, reflective experience.
- Curious visitors who want an artistic introduction to themes associated with Siva.
- Mobile and desktop users who need accessible interaction modes.

## Core functionality for this milestone
- 3D Explorer with smooth rotation and zoom.
- Selectable sacred symbols using procedural geometry.
- English/Tamil descriptions for each selection.
- Quiet "Just Siva" mode that hides explanations and markers.
- Mobile-friendly touch controls.
- Reduced motion and graphics quality settings.
- Accessibility-aware labels and contrast.

## Design constraints
- Siva is treated as Pati, not as a single embodied being merged with the individual soul (Pasu).
- Never invent scriptural references or claim canonical citations.
- Clearly mark all work as artistic interpretation.
- Use procedural geometry for the first implementation and intentionally document the upgrade path to Blender models.
- Stop after the Explorer milestone; do not add unrelated modules.

## Non-goals for this milestone
- Full theology database.
- Multi-module app architecture beyond the Explorer.
- Production-grade asset pipeline before the first working experience is complete.
