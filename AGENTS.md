# AGENTS.md

## Mission
This repo is a contemplative interactive 3D experience honoring Lord Siva. The first milestone is a working Explorer module that exposes a quiet, meditative 3D space in a browser using Next.js, TypeScript, Three.js, and React Three Fiber.

## Required design principles
- Preserve Siva as Pati, the Supreme Principle, distinct from individual souls, Pasu.
- Do not invent scriptural citations or attribute textual references that are not explicitly known.
- Clearly label artistic interpretations as interpretive and devotional, not doctrinal claims.
- Keep the experience contemplative, accessible, and minimal.
- Use procedural geometry in this milestone and document the path to professional Blender replacement.
- Finish the Explorer milestone before adding other modules.

## Implementation rules
- Use Next.js + TypeScript + Three.js + React Three Fiber.
- Provide a first-person style or orbit-exploration view with rotation, zoom, and symbol selection.
- Include English and Tamil explanations on selected sacred symbols.
- Include a view named "Just Siva" that hides markers and explanatory overlays.
- Support mobile interaction, reduced motion, and user-controlled graphics quality.
- Add accessibility-friendly buttons, labels, and readable contrast.
- Keep all explanatory text honest: no invented scriptural references, no hidden doctrinal claims.

## Completion gate
Before any other module is added, complete the first working Explorer with production-ready code, a passing test script, and a successful production build.
